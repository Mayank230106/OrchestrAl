# OrchestrAI Frontend

This directory will contain the React application for the OrchestrAI Mission Control dashboard.

## Planned Features:
- Split-pane Mission Control dashboard.
- Live execution graph of agent interactions.
- Terminal telemetry for viewing agent reasoning.
- Human-in-the-Loop (HITL) approval cards for confirming actions drafted by the agents.
